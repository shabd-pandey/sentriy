# 01: Bringing the MarvelSyllabus movie catalog to life

**What to build:** Customers browse and discover the shared film-and-series catalog through the supplied cinematic movie-booking design, with MarvelSyllabus branding and the tagline “Burden with Glorious Syllabus.”

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] The customer catalog applies the supplied Movie Booking Interface visual direction to the existing combined film/series catalog without replacing its shared data source.
- [ ] The MarvelSyllabus name and exact tagline “Burden with Glorious Syllabus” appear in the customer experience.
- [ ] Catalog titles retain the admin-managed global watch order, visible film/series type, and Upcoming state for inactive titles.
- [ ] Customers can move from a title to its screenings; screening cards remain chronologically ordered and use existing booking availability rules.
- [ ] Poster artwork is lazy-loaded with reserved dimensions; the watchlist JSON and Figma source archives are not bundled in the browser.
- [ ] The layout remains usable at mobile and desktop sizes, with keyboard-operable controls, visible focus, adequate contrast, and reduced-motion support.
- [ ] End-to-end acceptance verifies catalog order, Upcoming behavior, screening discovery, and that unavailable titles cannot be booked.
